# mini-cad-measure Product Notes

## Positioning

mini-cad-measure is an internal learning demo for a lightweight 2D SVG CAD measuring workflow. It is not intended to become a full CAD system.

## First Phase Scope

- Create a Vite, React, TypeScript project shell.
- Provide a stable application layout with a top toolbar, left tool palette, central SVG canvas, right properties panel, and bottom status bar.
- Prepare engineering configuration for linting, formatting, unit tests, build, and future browser tests.
- Keep drawing, selection, measurement, history, and local persistence as follow-up implementation work.

## Target Capabilities

- 2D SVG CAD canvas.
- Pan, zoom, grid, and coordinate display.
- Draw lines, rectangles, and circles.
- Select objects and inspect properties.
- Measure distance between two points.
- Undo, redo, and local save.

## Non-goals

- No file import.
- No 3D.
- No backend service.
- No attempt to replicate a full CAD feature set.
